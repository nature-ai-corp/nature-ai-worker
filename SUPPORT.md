# Support and community

Nature AI Worker is maintained by **NATURE AI CORP** as an open-source project.

## Where to ask

- **Questions, setup advice, model compatibility, and ideas:** [GitHub Discussions](https://github.com/nature-ai-corp/nature-ai-worker/discussions) (once Discussions are enabled).
- **Reproducible bugs and scoped feature requests:** [GitHub Issues](https://github.com/nature-ai-corp/nature-ai-worker/issues).
- **Security vulnerabilities, exposed secrets, or private infrastructure:** follow [SECURITY.md](SECURITY.md). **Do not post these publicly.**
- **Contributing code or documentation:** follow [CONTRIBUTING.md](CONTRIBUTING.md).

## Help us help you

Before opening a question, check the [README](README.md), the [v0.1.1 release notes](https://github.com/nature-ai-corp/nature-ai-worker/releases/tag/v0.1.1), and existing discussions or issues. For a bug, share the Worker version, operating system, model provider, steps to reproduce, expected behavior and actual result. Remove API keys, tokens, personal files, private URLs and customer information from logs and screenshots.

Nature AI Worker is an early single-user, locally hosted project. Community responses are best effort and do not imply guaranteed response times or enterprise support contracts. NATURE AI Platform Server and private enterprise implementation are not part of this open-source project.
