# Community Code of Conduct

NATURE AI CORP welcomes respectful collaboration on Nature AI Worker.

Be constructive, considerate and patient. Disagree with ideas rather than attacking people. Do not harass, threaten, discriminate, impersonate others, spam, or post deceptive or malicious content. Respect people's privacy and intellectual property.

Keep discussions relevant to Nature AI Worker, its documented features, models, tools, installation, security and ecosystem. Do not post credentials, confidential customer data or private NATURE AI Platform information. Follow [SECURITY.md](SECURITY.md) to report vulnerabilities privately.

Maintainers may edit or remove content, close or lock threads, and restrict participation in accordance with GitHub policies when needed to keep the community safe. Decisions should be based on conduct and evidence, not disagreement with a technical opinion.

Report conduct problems using the repository's GitHub moderation/report mechanisms. For sensitive security reports, use GitHub Private Vulnerability Reporting as described in [SECURITY.md](SECURITY.md). Do not disclose another person's private information in a public issue or discussion.
